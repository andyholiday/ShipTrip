## 📝 Description (max 4000 Zeichen)

```
Dein digitales Kreuzfahrt-Tagebuch! 🚢

ShipTrip ist die perfekte App für alle Kreuzfahrt-Enthusiasten. Dokumentiere deine Reisen, visualisiere Routen auf der Weltkarte und behalte den Überblick über alle deine Abenteuer auf See.

FEATURES:

📋 REISEVERWALTUNG
• Erstelle detaillierte Einträge für jede Kreuzfahrt
• Speichere Schiff, Kabine, Reederei und Reisedaten
• Füge Notizen und Bewertungen hinzu

🗺️ INTERAKTIVE WELTKARTE
• Visualisiere alle deine Routen auf einer Weltkarte
• Über 1.800 Häfen weltweit in der Datenbank
• Sieh auf einen Blick, wo du schon überall warst

✨ KI-BUCHUNGSIMPORT
• Füge einfach deinen Buchungstext ein
• Die KI extrahiert automatisch alle Daten
• Spart Zeit bei der Dateneingabe

📊 STATISTIKEN
• Anzahl der Kreuzfahrten, Seetage und Häfen
• Besuchte Länder auf einen Blick
• Deine persönliche Kreuzfahrt-Geschichte

📸 FOTOGALERIE
• Speichere Erinnerungsfotos zu jeder Reise
• Hafen-Bilder und Bordimpressionen

💰 AUSGABENVERFOLGUNG
• Dokumentiere Bordausgaben
• Behalte dein Budget im Blick

🔄 EXPORT & IMPORT
• Sichere deine Daten als ZIP-Archiv
• Importiere Kreuzfahrten von anderen Geräten

☁️ PRIVATER ICLOUD-SYNC
• Synchronisiere deine Reisedaten über deinen Apple-Account
• Spiegle Reisen optional in einen ausgewählten Kalender

Die App unterstützt Deutsch und Englisch. Reisedaten werden lokal gespeichert und
über den privaten iCloud-/CloudKit-Bereich des Apple-Accounts synchronisiert;
ShipTrip betreibt dafür keine eigenen Server.

Starte jetzt deine digitale Kreuzfahrt-Sammlung!
```

## 📋 Review Notes (für Apple Reviewer)

```
This app uses Google Gemini AI for extracting cruise booking data from pasted text. The AI is used purely for text parsing and does not collect or store user data.

Demo data can be created by using the AI import feature with sample booking texts.

No login is required. Travel data is stored locally and synchronized through
the private iCloud/CloudKit area of the user's Apple Account. Calendar sync is
optional and writes only to the calendar selected by the user.
```
